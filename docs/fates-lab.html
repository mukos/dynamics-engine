Fate Lab

Every card is one reduced universe simulated live from the zero state: the first step fires every channel, then the state evolves on its own. Press a card's play button to run it. Portrait plots the state in the plane; Waves plots every coordinate against time (one dash pattern per coordinate, see each chart's legend); Radial wraps time around the circle, one turn per 60 steps, with the radius as the size of the state (thick: ‖v‖, thin: each |ve|).
