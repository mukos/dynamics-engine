Five Fates

Phase portraits of real trajectories from the exact analyser. Inside each quadrant the velocity is constant, so every path is a chain of straight segments that bend only on the axes.

v(t+1) = v(t) + d(sign v(t))
d ∈ {−N…N}N per sign pattern
lattice: ℤ2 (projected for N = 3)
start — state after the first step, when every channel fires (or the chosen start)
fixed point — the velocity here is zero
transient — part of the path visited once
continuation — proven by the certificate, not simulated
quadrant labels — the sign pattern that selects the velocity there
