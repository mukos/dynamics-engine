§5

How it is built

The engineering

A dependency-free Rust codebase that turns an exponential search into seconds: reduce the space, prove instead of simulate, and keep the hot loop out of the allocator's way.

exact, not simulated

Event-driven certificates

The analyser jumps from one sign change to the next instead of stepping. A repeated state proves a cycle; a quadrant the velocity cannot leave proves a ray; a replayed segment v(t+T) = v(t) + D proves a helix.

symmetry

Canonical forms

Fates are invariant under the hyperoctahedral group of signed permutations. Burnside's lemma counts the orbits: 873 classes at N = 2, 8,093,160 at N = 3.

reduction

From bits to ternary rows

Only differences between paired channels matter, so 24N² bit matrices collapse to 32N² universes, each carrying a multiplicity of 2zeros.

performance

Out of the allocator's way

Static musl builds serialise threads on malloc. Reusing one workspace per thread and walking indices with an odometer removed every allocation from the hot loop. Size-3 census on 8 cores:

first Rust version527 s
allocation-free loop6.6 s
80× faster, same answers
verified

Tests that pin the maths

Certificates are checked against brute-force simulation, the index odometer against decoding, and the original TypeScript histogram is kept as a regression test.

# every three-element universe, exactly, in about seven seconds
$ cargo run --release -- exact --size 3
# two billion four-element universes, sampled with a fixed seed
$ cargo run --release -- exact --size 4 --samples 2000000000
# replay one universe event by event
$ cargo run --release -- show --size 3 --index 27411247
§6

The mathematics

The rule and its theory

Locally the system is trivial: a straight line. Globally it is as hard as computation itself. The interesting mathematics is in between, on the loops.

around one loop of quadrants, the return map is affine: x ↦ Ax + b
A = I, b = 0the state comes back exactly: a cycle
A = I, b ≠ 0it comes back shifted by the same vector: a helix
ρ(A) > 1each return is larger, like x ↦ 2x + 13: a spiral
no loop at alla quadrant it never leaves: a ray; zero velocity: fixed
Piecewise-constant derivativesThe continuous cousin: reachability is decidable in two dimensions and undecidable from three, which is why spirals stay empirical.Asarin, Maler, Pnueli (1995)
Glass networksGene-regulation models whose vector field depends only on which side of thresholds each variable lies.Glass, Kauffman (1973)
Karp–Miller coverabilityThe helix certificate is its deterministic analogue: a repeated pattern whose gain keeps every sign repeats forever.Karp, Miller (1969)
